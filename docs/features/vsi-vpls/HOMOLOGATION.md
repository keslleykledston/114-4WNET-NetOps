# Homologation

## Roteiro manual

1. Abrir `L2 Circuits > VSI/VPLS`.
2. Verificar carregamento da lista.
3. Filtrar por `VS-ID`.
4. Abrir detalhe.
5. Conferir membros.
6. Conferir dispositivos.
7. Expandir config de cada dispositivo.
8. Validar alerta de PW down.
9. Validar status consolidado.
10. Validar historico.
11. Validar ausencia de segredo.
12. Validar build/test/lint.
