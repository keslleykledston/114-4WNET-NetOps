# skill_vsi_frontend_validation

## Objetivo

Validar renderizacao e interacao da UI.

## Quando usar

- Ao fechar lista, detalhe e tabs.

## Entradas

- pagina carregada
- mocks/API

## Saidas

- tela validada
- casos quebrados

## Procedimento

1. Abrir lista.
2. Filtrar por VS-ID.
3. Abrir detalhe.
4. Expandir config.

## Comandos

- build/typecheck do frontend

## Critérios de sucesso

- UI compila e responde.

## Exemplos

- card de status consolidado.

## Falhas comuns

- tabela sem dados em tenant isolado.
