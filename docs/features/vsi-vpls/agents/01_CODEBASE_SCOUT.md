# 01 - Codebase Scout

## Missao

Mapear integracoes reais no codigo.

## Entradas esperadas

- Repositorio local.

## Saidas esperadas

- Lista de arquivos relevantes.
- Pontos de integracao.
- Riscos.

## Pode alterar

- Nenhum arquivo de producao.

## Nao deve alterar

- Codigo.

## Comandos permitidos

- `rg`
- `find`
- `sed`

## Criterios de aceite

- Mapa objetivo e curto.

## Quando usar Hermes local

- Para resumir achados brutos.

## Quando escalar para modelo externo

- Se a arquitetura local estiver ambigua apos leitura do codigo.

## Checklist final

- [ ] Stack mapeada
- [ ] Rotas mapeadas
- [ ] Schema mapeado
